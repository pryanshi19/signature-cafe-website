# Signature Cafe — Website

A responsive website for **Signature Cafe**, a rooftop café in Majnu-Ka-Tilla, New Delhi. Built as a Web Development course final project.

## About

Signature Cafe is a real rooftop café overlooking the Yamuna River and the Signature Bridge. This site was built from scratch (HTML5, CSS3, vanilla JavaScript — no frameworks) using publicly available information about the business (menu, hours, address, phone, and guest reviews).

## Features

- Responsive, mobile-first layout with a mobile nav menu
- Hero, About, Menu, Gallery, Reviews, Visit/Location, and Reservation sections
- Embedded Google Map
- Client-side reservation form with confirmation message
- WhatsApp quick-contact button

## Tech Stack

- HTML5 / CSS3 / vanilla JavaScript
- Google Fonts (Cormorant Garamond, Manrope)
- Hosted on GitHub Pages
